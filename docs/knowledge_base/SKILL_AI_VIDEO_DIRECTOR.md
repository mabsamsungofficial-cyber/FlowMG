# Skill: Autonomous AI Video Director & Generative Scene Architecture

## Overview
This skill teaches the AI Video Director how to turn ANY arbitrary story or script into a high-retention, professionally directed animated video (9:16 vertical 1080x1920 @ 60fps). 

The AI does NOT pick from rigid templates. Instead, the AI functions as a **Creative Director & Motion Graphic Code Synthesizer**: it analyzes the script line-by-line, conceives bespoke visual metaphors, decides the narrative pacing, schedules causal animations to audio beats, and dynamically designs the visual elements.

---

## 1. The Core AI Generation Pipeline

```
Raw Story / Script
       │
       ▼
[1. AI Director Script Breakdown]
       │ ── Identifies core narrative beats & emotional peaks
       │ ── Chooses overall visual atmosphere (mood, palette, character)
       │ ── Conceives visual metaphors for each scene
       ▼
[2. Gemini Live Voiceover & Phonetic Timing]
       │ ── Generates conversational, expressive voiceover
       │ ── Extracts exact word timestamps & audio duration
       ▼
[3. Dynamic Scene Graph Synthesis]
       │ ── Positions visual elements (mockups, step-loops, data cards, props)
       │ ── Chains causal animations to voice syllables
       │ ── Maps character poses & lip-sync mouth shapes
       ▼
[4. Remotion Programmatic Rendering]
       │ ── Evaluates scene tree in headless Chromium
       │ ── Compiles 60fps MP4 video
```

## 2. Visual Metaphor Thinking Matrix

When reading a line of script, the AI Director asks: **"What visual object or diagram makes this concept click in 0.5 seconds?"**

| Script Content | Visual Metaphor Chosen by AI | Dynamic Elements Generated |
| :--- | :--- | :--- |
| **Startup / Business Strategy** | Step Loop / Value Flywheel | Sequential numbered badges, dashed arrows, central device or hub |
| **Financial / Unit Economics** | Fraction Split / Breakdown | Total benchmark box fracturing into component cost cards with math operators |
| **Competition / Disruption** | Contrast Split (Old vs New) | Two comparative cards, cross vs check badges, illuminated winner tag |
| **Customer / Market Scale** | Audience Matrix / Density Grid | Matrix of people/buyer icons with percentage lighting up in accent color |
| **Physical Product / Story** | Illustrated Prop or Mockup | Dynamic SVG props (store stall, coffee cup, delivery bike, donation box) |
| **Climax / Shocking Stat** | Giant Kinetic Punch Headline | Oversized bold typography with animated accent underline and cursive subtitle |
| **Investigation / Revelation** | Evidence Board / Network | Pin cards with connecting red threads and exhibit tags |

## 3. Motion & Animation Laws (Derived from HyperFrames)

1. **No Idle Wobble:** Never insert meaningless floating or breathing loops. If an element is on screen, it either entered with intent, is reacting to a voice beat, or is paying off a reveal.
2. **Causal Timing:** Motion starts on the exact word/frame of speech. When narrator says *"do hazaar"* (two thousand), the `Rs 2,000` card pops on that exact millisecond.
3. **The Carrier Rule:** Across scene cuts, hand over a carrier element (the character stays engaged, or an arrow or phone anchors the eye).
4. **Audio is the Clock:** All visual durations derive strictly from real voiceover timestamps.
